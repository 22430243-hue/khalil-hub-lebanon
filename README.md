# KhalilHub

## Project Description
KhalilHub is a web application for discovering and exploring events. Users can browse upcoming events, view event details, learn about the platform on the About page, and contact the team via the Contact page. It is built with React for a fast and interactive user experience.

## Features
- Home page with featured events 
- Events page to browse all events
- About page: Presents the organization's story, mission, and founder information.
- Contact page: Allows users to contact the organization and submit inquiries.
- Responsive Navigation Bar and Footer

## Technologies Used
- React.js
- JavaScript (ES6)
- CSS
- React Router DOM

## Setup Instructions
1. Clone the repository 
     git clone https://github.com/22430243-hue/khalil-hub-lebanon.git

2. Navigate to the project folder
     cd eventhub

3. Install dependencies
     npm install

4. Run the application
     npm start

The application will run on:
http://localhost:3000
